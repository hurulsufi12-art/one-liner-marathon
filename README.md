Entry for the [One-Liner Marathon bounty on make.fun](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2).

A Python 3 stdlib-only program that writes a single one-line joke (152 characters, ASCII-only) to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to write somewhere else (defaults to `/output` when unset or empty):

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

## The joke

> The museum audio guide spent three minutes on the painting and two on the frame, then described my reflection in the glass as an early work, unfinished.
